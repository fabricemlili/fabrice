## Try My Work Using UV
Run each script one by one. Press Ctrl + C to stop the current script and move to the next one.
```bash
cd python_files
uv run all
```

## Or run with your python env
First, activate your python environment:
```bash
source /path/to/your/venv/bin/activate
```

Then run each script one by one. Press Ctrl + C to stop the current script and move to the next one.
```bash
cd python_files
python -m /src/python_files
```
